# External Integrations & Services

**Analysis Date:** 2026-08-11

## Overview of External Systems

The system integrates with external authentication providers, internal REST microservices, GIS map tile providers, and IoT hardware telemetry streams.

---

## Integrations Catalog

### 1. Clerk Authentication (`Clerk Auth`)

- **Role**: Identity Provider (IdP) for User Authentication & JWT Session Token management.
- **Frontend Integration (`@clerk/nextjs`)**:
  - Middleware: `frontend/src/middleware.ts` uses `clerkMiddleware` to protect dashboard routes (`/dashboard`, `/animals`, `/farms`, `/geolocalizacion`, `/zonas`, `/animal-types`).
  - Auth Pages: Catch-all routes `frontend/src/app/(auth)/sign-in/[[...sign-in]]/page.tsx` and `frontend/src/app/(auth)/sign-up/[[...sign-up]]/page.tsx`.
- **Backend Integration (`@clerk/backend` & `Svix`)**:
  - Guard: `backend/src/auth/clerk-auth.guard.ts` verifies incoming HTTP `Authorization: Bearer <token>` headers using Clerk's `verifyToken`.
  - Provider: `backend/src/providers/clerk.provider.ts` initializes the Clerk client SDK.
  - Webhook Endpoint: `backend/src/webhook/webhook.controller.ts` receives Clerk `user.created`, `user.updated`, `user.deleted` events using Svix (`svix.Webhook`) to synchronize user profiles in local database (`User` model in `backend/prisma/schema.prisma`).

### 2. ML Health Prediction Microservice (`ml-service`)

- **Role**: Machine learning inference API for livestock biometric anomaly detection (fever, hypothermia, physical inactivity).
- **Communication Protocol**: Internal HTTP REST call from NestJS backend to Python FastAPI.
- **Endpoint Called**: `POST http://ml-service:8000/predict/health` (configured via environment variable `ML_SERVICE_URL`).
- **Caller Service**: `backend/src/iot/iot.service.ts` converts collar telemetry windows into `PredictionRequest` payloads and triggers health alerts when `anomaly_detected` is returned.

### 3. OpenStreetMap / Leaflet Tile Server (`Leaflet GIS`)

- **Role**: Map tile rendering for interactive geolocation and livestock monitoring.
- **Integration**: `frontend/src/components/maps/LiveTrackingMap.tsx` and `frontend/src/components/maps/ZoneMap.tsx`.
- **Tile Provider**: OpenStreetMap raster tiles fetched via client browser.

### 4. IoT Telemetry Collar Stream (`IoT Hardware / Simulator`)

- **Role**: Ingestion of GPS coordinate streams and temperature readings from physical/simulated livestock collars.
- **Endpoint**: `POST /api/iot/telemetry` on `backend/src/iot/iot.controller.ts`.
- **Simulator Scripts**:
  - `scripts/iot_simulator.js`: Periodic telemetry stream simulator sending lat/lng and body temperature.
  - `scripts/iot_escape_test.js`: Test script simulating a boundary escape event to trigger geofence alerts.

### 5. PostgreSQL + PostGIS Spatial Database

- **Role**: Spatial and relational data persistence (polygon geofences, sectors, collar locations, animals, alerts).
- **Database Target**: `postgresql://postgres:postgres@db:5432/damp_db`.
