# Technical Stack

**Analysis Date:** 2026-08-11

## Architecture & Service Topology

The project is structured as a multi-service monorepo managed via Docker Compose (`docker-compose.yml`), comprising three primary runtime components:

1. **Backend Service (`/backend`)**: NestJS REST API microservice handling business domain logic, authentication, GIS spatial queries, database persistence, IoT telemetry reception, and integration with the ML service.
2. **Frontend App (`/frontend`)**: Next.js App Router web application providing an interactive dashboard for farm management, GIS live tracking, telemetry visualization, geofencing, and animal management.
3. **ML Microservice (`/ml-service`)**: Python FastAPI microservice providing machine learning inference (health anomaly detection based on biometric telemetry).
4. **IoT Simulators (`/scripts`)**: Node.js simulation scripts for IoT telemetry and geofence escape events.

## Service Breakdown & Dependencies

- **Language / Runtime**: Node.js / TypeScript (`^5.7.3`), target ES2021 (`tsconfig.json`).
- **Framework**: NestJS v11 (`@nestjs/core` `^11.0.1`, `@nestjs/common` `^11.0.1`).
- **HTTP Server**: Express (`@nestjs/platform-express` `^11.0.1`).
- **Database & ORM**: PostgreSQL with PostGIS extension, Prisma ORM v7 (`@prisma/client` `^7.8.0`, `prisma` `^7.8.0`, `@prisma/adapter-pg` `^7.8.0`, `pg` `^8.20.0`).
- **Authentication & Security**: Clerk Backend SDK (`@clerk/backend` `^3.4.2`), Svix Webhooks (`svix` `^1.93.0`).
- **Validation & Transformation**: `class-validator` (`^0.15.1`), `class-transformer` (`^0.5.1`), `@nestjs/mapped-types`.
- **Configuration**: NestJS Config (`@nestjs/config` `^4.0.4`), RxJS (`^7.8.1`).
- **Testing & Tools**: Jest (`^30.0.0`), Supertest (`^7.0.0`), ESLint v9 (`^9.18.0`), Prettier (`^3.4.2`).

### 2. Frontend Application (`/frontend`)

- **Framework**: Next.js v16 App Router (`next` `16.2.4`), React v19 (`react` `19.2.4`, `react-dom` `19.2.4`).
- **Language**: TypeScript (`^5`).
- **Styling**: Tailwind CSS v4 (`tailwindcss` `^4`, `@tailwindcss/postcss` `^4`), Vanilla CSS with CSS custom properties (`src/styles/tokens/`).

### 3. ML Inference Service (`/ml-service`)

- **Runtime**: Python 3.11 (Alpine/Slim base image in `ml-service/Dockerfile`).

- **Database Container**: `postgis/postgis:15-3.3-alpine` running on port 5435 locally (`5435:5432`).
- **Containerization**: Docker & Docker Compose (`docker-compose.yml`, `ml-service/Dockerfile`, `backend/Dockerfile`).
