## Naming Conventions

### File & Directory Naming
- **Backend (NestJS)**: Kebab-case with feature suffix:
  - Modules: `farms.module.ts`, `animals.module.ts`
  - Controllers: `farms.controller.ts`, `api-animals.controller.ts`
  - Services: `farms.service.ts`, `iot.service.ts`
  - DTOs: `create-animal.dto.ts`, `update-animal.dto.ts`
- **Frontend (Next.js)**:
  - Components: PascalCase (`KpiCard.tsx`, `LiveTrackingMap.tsx`, `SidebarLink.tsx`)
  - Hooks: camelCase with `use` prefix (`useApi.ts`, `useMutation.ts`)
  - Next.js Routes: Lowercase/kebab-case directory names (`app/(dashboard)/geolocalizacion/page.tsx`)
  - Types/Interfaces: Kebab-case files (`types/animal.ts`, `types/geofence.ts`)

### Database Table & Column Naming (Prisma)
- **Prisma Models**: PascalCase (`User`, `Farm`, `FarmUser`, `Animal`, `Sector`, `Geofence`).
- **Database Tables**: Explicitly mapped to snake_case singular/plural using `@@map("...")`:
  - `User` -> `@@map("users")`
  - `Farm` -> `@@map("farm")`
  - `Role` -> `@@map("role")`
  - `FarmUser` -> `@@map("farm_user")`
  - `Animal` -> `@@map("animal")`
- **Columns**: Explicitly mapped to snake_case using `@map("...")`:
  - `clerkId` -> `@map("clerk_id")`
  - `createdAt` -> `@map("created_at")`
  - `birthDate` -> `@map("birth_date")`

## Backend Architecture Conventions (NestJS)

- **Dependency Injection**: Services decorated with `@Injectable()` and injected via constructor parameter properties.
- **Validation**: DTOs use `class-validator` decorators:
  ```typescript
  export class CreateAnimalDto {
    @IsString()
    @IsNotEmpty()
    farmId: string;

    @IsString()
    @IsOptional()
    tag?: string;
  }
  ```
- **Authentication**: Routes requiring user context use `@UseGuards(ClerkAuthGuard)` and `@CurrentUser()`.

---

## Frontend Architecture Conventions (Next.js)

- **Component Design**: Functional components typed with standard React props interfaces.
- **CSS Token Design System**: Prefers custom CSS variables defined in `src/styles/tokens/colors.css` and `src/styles/tokens/typography.css` alongside Tailwind CSS v4 utilities.
- **State & Data Fetching**: Encapsulated in custom hooks (`useApi`, `useMutation`) with feedback handled by `ToastContext`.
