    3. Create `backend/src/admin/admin-users.controller.ts`:
       - Annotated with `@Controller('admin/users')`, `@UseGuards(ClerkAuthGuard, GlobalRolesGuard)`, `@GlobalRoles(GlobalRole.SUPER_ADMIN)`.
       - `GET /` -> `findAll()`.
       - `PATCH /:userId/role` -> `updateGlobalRole(@Param('userId') userId, @Body() dto)`.

       - Export `AdminUsersService`.

<task type="auto">
  <name>Task 2: Build Farm Sub-user Administration API (FarmUsersModule)</name>
  <files>
    backend/src/farm-users/dto/assign-farm-user.dto.ts
    backend/src/farm-users/dto/update-farm-user.dto.ts
    backend/src/farm-users/farm-users.service.ts
    backend/src/farm-users/farm-users.controller.ts
    backend/src/farm-users/farm-users.module.ts
  </files>
  <read_first>backend/src/farms/farms.service.ts</read_first>
  <action>
    1. Create DTOs in `backend/src/farm-users/dto/`:
       - `AssignFarmUserDto`: `userId: string` (or `userEmail: string`), `roleName: string` (`ADMIN`, `OPERATOR`, `VIEWER`).
       - `UpdateFarmUserDto`: `roleName: string`.
    2. Create `backend/src/farm-users/farm-users.service.ts`:
       - `findAllInFarm(farmId: string)`: Returns `FarmUser` records for `farmId` with `user` and `role` included.
       - `assignSubUser(farmId: string, dto: AssignFarmUserDto)`: Finds `Role` by `roleName` (creates if missing or throws), finds or creates `User`, upserts `FarmUser`.
       - `updateSubUserRole(farmId: string, userId: string, dto: UpdateFarmUserDto)`: Updates `roleId` of `FarmUser`.
       - `removeSubUser(farmId: string, userId: string)`: Deletes `FarmUser` link in Prisma.
    3. Create `backend/src/farm-users/farm-users.controller.ts`:
       - Annotated with `@Controller('farms/:farmId/users')`, `@UseGuards(ClerkAuthGuard, GlobalRolesGuard, FarmRoleGuard)`.
       - `GET /` -> `findAllInFarm(@Param('farmId') farmId)`.
       - `POST /` -> `@RequireFarmRole('ADMIN')` `assignSubUser(@Param('farmId') farmId, @Body() dto)`.
       - `PATCH /:userId` -> `@RequireFarmRole('ADMIN')` `updateSubUserRole(@Param('farmId') farmId, @Param('userId') userId, @Body() dto)`.
       - `DELETE /:userId` -> `@RequireFarmRole('ADMIN')` `removeSubUser(@Param('farmId') farmId, @Param('userId') userId)`.
    4. Create `backend/src/farm-users/farm-users.module.ts`.
  </action>
  <verify>cd backend && pnpm run build</verify>
  <acceptance_criteria>
    - FarmUsersController handles GET, POST, PATCH, DELETE under /farms/:farmId/users
    - Mutation endpoints protected by RequireFarmRole('ADMIN')
  </acceptance_criteria>
  <done>Farm Sub-user Administration API created.</done>
</task>
