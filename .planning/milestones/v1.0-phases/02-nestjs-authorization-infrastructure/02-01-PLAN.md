<task type="auto">
  <name>Task 2: Implement GlobalRolesGuard and FarmRoleGuard</name>
  <files>
    backend/src/auth/guards/global-roles.guard.ts
    backend/src/auth/guards/farm-role.guard.ts
  </files>
  <read_first>backend/src/auth/clerk-auth.guard.ts</read_first>
  <action>
    1. Create `backend/src/auth/guards/global-roles.guard.ts`:
       - Inject `Reflector` and `PrismaService`.
       - Check `GLOBAL_ROLES_KEY` metadata. Return `true` if empty.
       - Read `request.user` (Clerk token payload with `sub`).
       - Fetch `User` from Prisma by `clerkId`. Store as `request.dbUser`.
       - If `requiredRoles.includes(dbUser.globalRole)`, return `true`; else throw `ForbiddenException`.
    2. Create `backend/src/auth/guards/farm-role.guard.ts`:
       - Inject `Reflector` and `PrismaService`.
       - Check `REQUIRE_FARM_ROLE_KEY` metadata.
       - Read `request.dbUser` (or fetch from DB by `request.user.sub` if not attached yet).
       - **SuperAdmin Override**: If `dbUser.globalRole === 'SUPER_ADMIN'`, return `true`.
       - Extract `farmId` from `request.params.farmId` || `request.params.id` || `request.body.farmId` || `request.query.farmId`.
       - Query `prisma.farmUser.findUnique({ where: { farmId_userId: { farmId, userId: dbUser.id } }, include: { role: true } })`.
       - If not found, throw `ForbiddenException('User is not a member of this farm')`.
       - If required farm roles specified, verify `requiredRoles.includes(farmUser.role.name)`. Return `true` or throw `ForbiddenException`.
  </action>
  <verify>cd backend && pnpm run build</verify>
  <acceptance_criteria>
    - GlobalRolesGuard implemented with Prisma lookup
    - FarmRoleGuard implemented with SuperAdmin override and farm membership check
  </acceptance_criteria>
  <done>Authorization guards implemented and ready for route protection.</done>
</task>
